# AIC page notes: обробка локальних даних

[English](PRIVACY.md) · [Українська](PRIVACY.uk.md)

Цей документ описує експериментальний компонент 0.7.0 для Chrome та Edge.
Статус випуску й межі перевірок наведені у [README](README.uk.md) та
[VERIFICATION](VERIFICATION.uk.md).

AIC не має сервера, облікового запису, телеметрії чи синхронізації. Усі ресурси
виконання входять до пакета. Політика контенту розширення блокує вихідні
з’єднання й віддалені вбудовані ресурси. AIC читає вміст сторінки лише після
вашої команди імпорту; він не редагує, не заповнює і не вставляє дані у вихідні
сайти. Відкриття посилання на джерело є звичайною навігацією браузера.

Нотатки, доменні AIC-документи, необов’язковий Global Shared, назви, URL, дати та
індекс навігації разом шифруються в локальному сховищі розширення. Доменні
значення показуються лише для точно такого самого протоколу, хоста і порту.
Global Shared — один явно створений запис, доступний на всіх сторінках цього
профілю браузера, зокрема без активної сторінки. Жоден із цих записів не
копіюється у Markdown сторінки й не вставляється на сайти.

Майстер-пароль не зберігається. Похідний ключ після розблокування існує лише в
довіреній пам’яті сесії браузера. Lock, перезапуск браузера, перезавантаження або
оновлення розширення видаляє ключ. Вбудованого ключа чи резервного ключа на диску
немає. Локальне й сесійне сховища мають явні обмеження доступу до довіреного
контексту; локальне сховище містить лише зашифровані дані.

Панель веде обмежений список недавніх сторінок лише коли активна й розблокована.
Вона не читає базу історії браузера й не збирає перегляд у фоні. Нотатки
слідують за активною сторінкою у вікні панелі. Ланцюжок предків містить лише
назви збережених нотаток і URL джерел для предків того самого origin за
сегментами шляху; Markdown предків і секретні поля не показуються.

Маніфест виключає Chrome Incognito та Edge InPrivate. AIC не змінює налаштування
приватності браузера. Нотатки у звичайних вікнах зберігаються локально, доки їх
не видалить користувач або браузер. Підтверджене видалення прибирає вибрану
локальну нотатку та її запис із недавньої історії AIC, але зберігає інші нотатки
й спільні AIC-дані точного origin. Відновлення потребує попередньої зашифрованої
копії. Приватний режим не є способом очищення нотаток.

Повний експорт бібліотеки містить Global Shared, зашифрований і потребує
початкового пароля копії. Під час злиття наявний локальний Global зберігається,
а пропущений імпортований запис позначається явно; початкова зашифрована копія не
змінюється. Експорт Markdown і Copy навмисно створюють відкритий текст, включно
із секретами. Copy section містить масковані й приховані фільтром рядки вибраної
секції. Інші програми, історія або синхронізація буфера та сайти призначення
можуть отримати цей текст після вставлення. Мережеві обмеження AIC не керують
цими системами або звичайною службою оновлень браузера.

Видалення розширення видаляє його локальні дані, але не завантажені резервні
копії. Для unpacked-інсталяції зберігайте той самий шлях і використовуйте Reload
замість видалення. Серверного відновлення немає. Зберігайте копії та пам’ятайте
пароль. Невдалі або конфліктні чернетки лишаються в пам’яті для повтору чи
експорту, але не є стійким до аварії сховищем.

## Дозволи

- `storage`: зашифровані локальні дані й сесійний ключ розблокування; без
  `storage.sync`.
- `tabs`: визначення активної сторінки у вікні панелі та відкриття збережених URL
  джерел; без доступу до бази історії.
- `sidePanel`: показ панелі нотаток у Chrome й Edge.
- `activeTab` і `scripting`: явне читання сторінки або виділення без змін.
- Необов’язковий доступ до HTTP(S)-сайтів: запитується для вибраного origin під
  час імпорту, а не для всіх сайтів при встановленні. Його можна відкликати в
  налаштуваннях розширення.
- `clipboardRead`: явна дія Paste для порожнього типізованого поля читає останній
  текст після натискання користувача. Звичайне вставлення редактора лишається
  нативним; фонового читання, моніторингу, історії та загальної кнопки імпорту з
  буфера немає.
- `clipboardWrite`: явні дії копіювання, включно з прихованими значеннями.

Шифрування не захищає вже розблоковане розширення або скомпрометований
пристрій/браузер. Під час редагування відкритий текст є в пам’яті. Видимий текст,
назви й URL сторінок можуть містити конфіденційні дані; виключення значень форм
не є універсальним виявленням секретів. Ця збірка не є незалежно аудитованим
менеджером паролів.
