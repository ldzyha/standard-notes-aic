# AIC page notes — експериментальний компонент Chrome / Edge

[English](README.md) · [Українська](README.uk.md)

**Статус:** експериментальний компонент **0.9.2**, узгоджений з AIC 46.0.2,
AIC Notes 54.0.2 і спільним ядром 7.3.2. Це ще не випуск у магазині браузера і
не незалежно аудитований менеджер паролів. До завершення перевірок у
[VERIFICATION](VERIFICATION.uk.md) використовуйте синтетичні дані.

Порожні редаговані секретні частини (`*|`) показують **Generate password** на
будь-якій ширині панелі незалежно від назви. Параметри переносяться на вузьких
екранах. Генерація працює локально, не перезаписує заповнені значення й недоступна
в режимі читання.

Після успішного копіювання кнопка-іконка ненадовго показує галочку та повідомляє
стан для читача екрана. Більші заголовки секцій, окремий нейтральний фон груп і
легке чергування сірих рядків допомагають швидше знаходити записи.

Назви, email та логіни займають природну ширину. Спочатку ціле значення
переходить на наступний рядок; текст переноситься всередині лише тоді, коли
не вміщується на повній доступній ширині. Пароль має компактну кнопку копіювання
із замком, а короткі дані картки й TOTP-коди залишаються читабельними. Меню `+`
йде після останнього значення, записи розділяють легкі лінії. Сенсорні кнопки
зберігають область натискання 44 px.

Після виходу з редагування джерела AIC-блоку або перемикання всієї нотатки з
джерела у прев’ю рядки кожної секції сортуються за назвою: без урахування регістру
та з природним порядком чисел. Рядки без назви зберігають свій порядок наприкінці.
Порядок секцій, порядок значень і точний текст значень не змінюються. Відкриття
прев’ю, копіювання й ручне переставлення не запускають сортування.

Усі три способи встановлення наведені в
[єдиній інструкції випуску](../RELEASE_INSTALL.md).

## Підтримувана модель

Підтримуються лише настільні **Google Chrome і Microsoft Edge** на Chromium 140
або новішому. Обидва браузери використовують один пакет Manifest V3, один
адаптер бічної панелі й той самий канонічний AIC-редактор.

- Створюйте нотатку для точної активної URL або явно імпортуйте видимий текст,
  виділення чи Markdown-файл. Імпорт додає текст і не редагує сайт.
- Використовуйте Preview/Markdown, slash-шаблони й дії блоків. Копіювання є
  ручним; автозаповнення чи вставлення у поля сайту немає.
- Панель слідує за активною сторінкою свого вікна. Page належить точній URL,
  Domain Shared — точному origin, Global Shared — профілю браузера.
- Нотатки зберігаються локально. Одна нотатка відповідає одній точній URL разом
  із query та fragment. AIC пам’ятає до 100 недавніх URL лише коли панель
  активна й розблокована та не читає історію браузера.
- Облікового запису, сервера, телеметрії й синхронізації немає. Повна бібліотека
  переноситься зашифрованою копією; Markdown і буфер — явний відкритий текст.

## Компактна панель та імпорт

Сторінка без нотатки одразу відкриває редагований AIC-placeholder. Саме відкриття
або вихід не створює запис; перша зміна створює зашифровану локальну нотатку без
скидання редактора, виділення чи Undo.

Основна дія імпорту бере поточне читабельне виділення, а без нього — читабельну
сторінку. **↑ Markdown** імпортує файл, **↓ Markdown** завантажує поточну
нотатку. Незмінений placeholder замінюється точним імпортом; інакше текст
додається. Форми, редаговані елементи, прихований вміст, захищені сторінки й
недоступні frames не імпортуються.

Вузька панель не має фіксованої мінімальної ширини. Назва поля й усі її значення
переносяться разом у читабельні колонки без окремого горизонтального скролу лише
для значень. Меню лишаються в межах viewport і за потреби прокручуються всередині.
Панель має локальну довідку **?**, що не читає нотатки, сховище чи мережу.

## AIC-поля

Кожний розділювач задає тип наступного значення: `|` текст, `*|` секрет, `#|`
TOTP seed, `_|` картка, `1|` невикористаний одноразовий код і `0|` використаний.
Порожній, Card і One-time codes — лише шаблони цих типів. Новий блок починається
з порожнього текстового рядка для email, імені чи іншого ідентифікатора.
Account більше не є окремим preset; Password і TOTP додаються за потреби.

Копіювання `1|` переводить код у `0|`. Натискання використаного значення повертає
`1|` без копіювання. Edit відкриває сирий Markdown. Явна Paste-дія може заповнити
порожнє поле з поточного буфера після натискання; моніторингу й історії немає.
Генерація доступна для порожніх парольних полів на будь-якій ширині, з адаптивними
параметрами; заповнені поля та режим читання її не дозволяють.

## 0.9.2 — акордеони та індикація збереження

Коментарі до пов’язаного коду лишаються всередині свого акордеона з компактним
заголовком і читабельною вкладеністю. Незбережені зміни не змінюють фон редактора;
кнопка Save пульсує до збереження. За налаштування reduced motion індикатор
статичний, а стан збереження й далі залежить від підтвердження хоста.

## 0.9.1 — генерація пароля на вузьких екранах

Порожні парольні поля дозволяють генерацію на будь-якій ширині панелі. Параметри
переносяться; наявні значення та нотатки в режимі читання залишаються захищеними.

## 0.9.0 — читабельні записи та автоматичне сортування

Назви й значення AIC переносяться цілими елементами природної ширини. Пароль
копіюється компактною кнопкою із замком; останнє значення зберігає меню `+`.
Після виходу з редагування джерела рядки кожної секції сортуються за назвою;
порядок секцій, порядок значень і точні значення зберігаються.

## 0.8.0 — компактні credential rows

  Protected value стає малою copy-кнопкою із замком і шістьма крапками. Одне
  меню `+` додає Field, Row або Section після останнього значення, а записи

  кнопку **Вирізати** з іконкою ножиць. Вона копіює повний Markdown-блок перед

## Двомовна документація 0.6.1

Product, privacy і verification documents доступні англійською та українською й

## Mermaid і Markdown

У 0.6.0 Mermaid редагується як Markdown із живим прев’ю. Прев’ю має Copy, одну
іконку Edit і масштабування. Візуальний конструктор, drag-and-drop та поворот
видалені.

Інформаційна цитата `>`, попередження `!>` і помилка `!>>` мають різні акценти та
легкий фон. `>>> … <<<` лишається details-блоком. Горизонтальна лінія показується
по центру шириною 50–100 px із відступами. Незавершений потрійний backtick можна
редагувати; готовий код переходить у прев’ю після виходу курсора.

## Global, Domain і Page

**Global** створює один явно редагований AIC-запис у зашифрованому сховищі
поточного профілю. Просте відкриття не створює дані. Domain Shared належить одному
точному `scheme + host + port`, Page — одній точній URL. Усі три рівні мають
незалежні revisions і drafts; значення не успадковуються, не заміщують одне
одного й не вставляються на сайти.

**Copy section** копіює вибрану секцію як окремий fenced-блок `aic`, включно з
маскованими й прихованими фільтром рядками, але без заголовка картки та сусідніх
секцій. Джерельні пробіли й лапки можуть нормалізуватися, логічні значення і типи
зберігаються. Дія не редагує і не зберігає джерело.

## Шифрування й межі

Перед першою нотаткою задайте унікальний майстер-пароль від 12 Unicode-символів
до 1024 UTF-8 байтів. Нормалізація й пробіли зберігаються точно. **Без пароля
відновлення немає.**

WebCrypto створює AES-256-GCM ключ через PBKDF2-HMAC-SHA256 з 600 000 ітерацій і
випадковою 32-байтовою salt. Кожний запис має новий випадковий 96-бітний IV і
128-бітний tag. Уся бібліотека — Markdown, назви, URL, дати, навігація, Domain і
Global — шифрується до запису на диск.

Пароль не зберігається. Похідний ключ існує лише в довіреному `storage.session`.
Lock, перезапуск браузера, reload або update його видаляє. У `storage.local` є
лише ciphertext; дискового fallback немає.

Межі: 500 нотаток, 500 origin-записів, один Global, 512 КіБ UTF-8 на документ,
6 МіБ на розшифровану бібліотеку, 100 недавніх URL і 8 КіБ на URL. Формат
бібліотеки v3 читає v1/v2 без переписування; наступний запис використовує v3.
Старі версії розширення не прочитають v3, тому перед downgrade потрібна копія.

Шифрування захищає дані на диску, але не розблоковане розширення,
скомпрометований пристрій, Undo, експорт або буфер. Маскування — візуальна дія.

## Збереження, Lock і видалення

Текст автозберігається після короткої паузи. Save, Ctrl+S, blur спільного
редактора й дії блоків теж запитують збереження. Лише підтвердження фонового
сховища встановлює стан **Note saved**. Помилки й конфлікти зберігають чернетку
в пам’яті для повтору чи експорту. Дочекайтеся підтвердження перед закриттям.

Lock очищає редактор, Undo, навігацію, фільтри, імпортні буфери та відповіді в
усіх панелях. Файли на диску й системний буфер не очищаються. Підтверджене
видалення прибирає вибрану нотатку та її AIC history, зберігаючи інші нотатки,
Domain і Global. Відновлення можливе лише з попередньої зашифрованої копії.

Chrome Incognito та Edge InPrivate не підтримуються й вимкнені маніфестом.

## Збірка й локальне встановлення

Найпростіше встановлення готового пакета описане в
[`RELEASE_INSTALL.md`](../RELEASE_INSTALL.md). Для локальної збірки:

```bash
npm run build:browser
```

Команда створює `dist-browser/chromium/` і
`dist-browser/artifacts/aic-browser-chromium-0.9.2.zip`. Відкрийте
`chrome://extensions` або `edge://extensions`, увімкніть Developer mode,
натисніть **Load unpacked** і виберіть папку з `manifest.json`, не ZIP.

Перед оновленням дочекайтеся **Note saved**, експортуйте зашифровану копію і
збережіть пароль. Для unpacked-версії лишайте ту саму папку й натискайте Reload;
не видаляйте заповнене розширення.

## Дозволи й приватність

Усі runtime-ресурси входять до пакета, а CSP блокує вихідні з’єднання й віддалені
вбудовані ресурси. Відкриття посилання — звичайна навігація браузера. Детальний
двомовний опис наведено у [PRIVACY](PRIVACY.uk.md).

До публікації лишаються: повна перевірка пакета в Chrome й Edge, виправлення
знайденого, повторна збірка, окремі подання до магазинів і перевірка встановлення
після схвалення. GitHub ZIP сам по собі не є магазинною публікацією.
