# Нотатки AIC для Chrome та Edge

[English](README.md) · [Українська](README.uk.md)

[Умови й приватність](https://aic.dzyha.com/terms/uk/) ·
[Випуски та встановлення](https://aic.dzyha.com/releases/uk/) ·
[Як писати документи](https://aic.dzyha.com/how-to/uk/)

AIC редагує локальні Markdown-файли в бічній панелі браузера. PWA, браузерне
розширення та VS Code використовують однаковий Markdown і синтаксис блоків
`aic`. У браузері файл також можна пов’язати з URL сторінки. Ця сторінка описує
підготовлену версію зі звичайними файлами; публікація й схвалення в магазинах
перевіряються окремо.

## Відкрийте файли та почніть писати

Виберіть **Open file** або **Open folder** через файлове вікно браузера. Зміни
зберігаються безпосередньо в ці файли. Для папки відкриється дерево файлів;
виберіть нотатку для редагування. **More options → New file** створює порожній
документ у вибраному місці або за назвою всередині підключеної папки. Додавайте
звичайний Markdown або блок AIC за потреби.

Коли запам’ятованому розташуванню потрібно поновити доступ, показуються його назва
й одна кнопка **Continue**. Вона стає доступною після підготовки збереженого
файлового доступу й запитує дозвіл для того самого місця без повторного вибору.
Інший файл або папку можна відкрити через **More options**.

Сканування показує кількість перевірених записів, готових нотаток і поточний
шлях; загальний обсяг невідомий, тому відсотка немає. **Use found notes** зупиняє
обхід і залишає вже прочитані нотатки. **Scan again** після зупинки або
**More options → Refresh folder** явно запускає новий обхід. Після підключення
звичайне відкриття нотаток, зміни вкладок і збереження використовують наявний
індекс без повторного сканування папки.

Якщо в папці знайдено нотатки, дерево **Notes** відкривається автоматично.
Великі дерева показують дочірні рядки після розгортання, по 100 на кожному рівні;
**Show more** відкриває наступні. Пошук охоплює всі проіндексовані нотатки,
зокрема ті, чиї рядки ще не показані.

Розташування й стан збереження залишаються видимими. Перед закриттям дочекайтеся
підтвердження запису на диск. Якщо файл змінився зовні, був видалений або втратив
дозвіл, чернетка лишається незбереженою для повтору чи відновлення. AIC не
перезаписує новіший текст і не відтворює видалений файл автоматично. Відновіть
доступ, коли цього попросить браузер.

Відкрита панель утримує доступ до вибраного файла під час перезапуску фонового
сервісу. Коли дозвіл на запис закінчується, біля розташування з’являється
**Reconnect access**. Дія використовує вже вибраний файл або папку та повторює
збереження без заміни чернетки. Дозвіл лише на читання не позначається як готовність
до запису. Конфлікт файла показується як **File changed**, а не втрата дозволу.

Якщо браузер не показує запит дозволу в бічній панелі, виберіть
**More options → Open AIC in tab**, потім **Continue** у відкритій вкладці.
Вона використовує ті самі вибрані файли. Повернення до початкової панелі повторно
перевіряє доступ і дозволяє продовжити без нового файлового вікна. Відмова в доступі
залишає чернетку незбереженою.

Тривалість дозволу визначає браузер. Відновлення викликає звичайний запит доступу;
якщо Chrome пропонує **Allow on every visit**, цей вибір може зменшити кількість
повторних запитів. Дивіться [пояснення Chrome](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api).

Файли залишаються на диску після видалення розширення. При цьому видаляються
локальні копії відновлення та запам’ятований доступ. Після перевстановлення
виберіть той самий файл або папку. Для перенесення між пристроями використовуйте
власну файлову систему, Git, Google Drive чи іншу синхронізацію. AIC не має
сервера синхронізації.

Немає пароля застосунку, зашифрованого простору чи імпорту `.aicnotes`.
Наявні старі файли й невикористовувані дані попереднього розширення залишаються
без змін. Секретні поля маскуються в редакторі, але Markdown і локальні копії
відновлення містять відкритий текст. Шифруванням керують засоби пристрою чи диска.

## Нотатки й вебсторінки

Для підключеної папки **Link file to current page** пов’язує вибраний файл із
точною URL сторінки. Після вибору файлів натисніть **Follow active tab**, щоб
повернути навігацію за активною вкладкою. Саме відвідування сторінки не створює
нотаток. Папка зберігає зв’язки URL та областей
у `.aic/links.json`, а вміст залишається в Markdown-файлах.

Current, Shared і Global показують одну нотатку за раз. Current пов’язаний із
точною URL, Shared — із точним origin, Global — із вибраною папкою.
Перемикання очікує збереження й не копіює спільний вміст у поточну нотатку.
Усі три вкладки одразу відкривають той самий Markdown-редактор: текст, списки,
діаграми й блоки AIC можна поєднувати. Видимий шлях і дія **Download copy**
стосуються активної вкладки. Global залишається вибраною після зміни сторінки
браузера. Shared відповідає контексту сторінки; після вибору окремого файла
**Follow active tab** повертає цей контекст.
Дерево файлів дозволяє переглядати документи незалежно від вебсайту. Підключення
одного файла редагує лише його, без областей папки та URL-зв’язків.

Закріплення залишає нотатку відкритою під час навігації. Коли ви пишете в
закріпленій нотатці, посилання на пов’язані сторінки додаються як звичайний
Markdown і скасовуються разом із правкою. Саме перемикання сторінки нічого не
додає. Закріплення належить відкритій панелі.

## Редагування й імпорт

- Використовуйте прев’ю або джерело Markdown, slash-шаблони й спільні дії блоків.
  Те саме джерело відкривається у PWA та VS Code.
- Імпорт сторінки чи виділення читає вміст лише після вашої дії та надання доступу
  до сайту. Він додає текст у вибрану нотатку й не змінює сайт. Захищені сторінки,
  форми, поля введення та недоступні фрейми виключені.
- **Insert from file…** додає вміст іншого Markdown-файла до Current. **Open file**
  змінює вибране джерело, **Download copy** завантажує активну нотатку.
- Копіювання та Markdown-експорт містять вибраний текст, включно з маскованими
  секретами. Історія буфера й програми призначення не контролюються AIC.
- `|`, `*|`, `#|`, `_|`, `1|` та `0|` зберігають синтаксис звичайних,
  секретних, authenticator, карткових та одноразових значень. Генерація пароля
  працює локально й заповнює лише порожнє редаговане поле.
- **AIC guide** входить до пакета й працює офлайн. Публічна сторінка How to
  пояснює написання документів і спільний метод DDK.

Меню використовують SVG-іконки, клавіатурний фокус і сенсорні області натискання.
Прев’ю коду та Mermaid займають свою висоту, пропускаючи прокручування нотатки.

## Відновлення й оновлення

Під час редагування AIC запитує окрему локальну контрольну копію чернетки.
Підтверджена копія може пережити Reload чи перезапуск браузера; це ще не означає
збереження файла. Поточна копія прибирається після підтвердженого запису на диск.
Відновлені чернетки переглядаються явно й можуть бути збережені окремими файлами.
Відновлення не замінює файлів і не відтворює видалених нотаток автоматично.
Якщо запис копії не вдався, тримайте панель відкритою та збережіть чи експортуйте
чернетку перед закриттям.

Для unpacked-версії зберігайте ту саму папку й користуйтеся Reload. Видалення
розширення очищує локальні дані відновлення. Збережені файли на диску лишаються
без змін. Ця версія не переносить старі зашифровані нотатки.

## Локальна збірка

```bash
npm run build:browser
```

Команда створює `dist-browser/chromium/` і ZIP із номером версії у
`dist-browser/artifacts/`. У `chrome://extensions` чи `edge://extensions`
увімкніть Developer mode, натисніть **Load unpacked** і виберіть папку з
`manifest.json`. GitHub ZIP або успішна локальна збірка не є релізом у магазині.

Підтримуються настільні Google Chrome та Microsoft Edge. Incognito й InPrivate
вимкнені. Усі runtime-ресурси входять до пакета; немає облікового запису,
телеметрії, аналітики чи фонового читання сайтів. Деталі — у
[політиці приватності](PRIVACY.uk.md) та [записі перевірок](VERIFICATION.uk.md).
