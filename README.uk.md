`AIC` — Markdown-редактор для Standard Notes. Компонент реєструється як Code
note, тому Standard Notes показує підтримувану іконку `>_`, але `file_type: md`
і взаємозамінність зберігають текст нотатки звичайним Markdown. Заголовки,
списки, завдання, таблиці, типізовані AIC-поля, блоки коду, деталі й Mermaid
працюють без перетворення нотатки на закритий формат.

Повна технічна карта поведінки міститься у
[`FUNCTIONAL_INDEX.md`](FUNCTIONAL_INDEX.md). Єдина двомовна інструкція для
VS Code, Standard Notes і браузера — у
[`RELEASE_INSTALL.md`](RELEASE_INSTALL.md).

Поточний координований випуск: Standard Notes AIC **42.1.0**, AIC Notes для
VS Code **50.1.0**, експериментальний browser **0.7.0**, shared core **7.1.0**.
Таблиці, code fences, Mermaid, AIC/Properties і details мають спільну кнопку
**Вирізати**, яка копіює весь Markdown-блок перед видаленням. First-party
product і release docs доступні англійською та українською.

Development target shared core 7.2.0 робить щільні AIC rows компактними на
вузьких екранах: label займає лише обмежену ширину свого тексту, захищене
значення має copy-кнопку із замком і шістьма крапками, кнопки створення
продовжують останнє значення, а записи розділяє одна легка лінія.

У випуску 42.1.0 всі керовані preview-блоки — таблиці, code fences, Mermaid,
AIC/Properties і details — мають спільну кнопку **Вирізати** з
іконкою ножиць. Вона спочатку копіює повний Markdown-блок, а потім прибирає його
однією undoable operation. Якщо запис у clipboard не вдався, документ не
змінюється.

## Поля безпеки

### Перетворення Authenticator JSON

Відкрийте початковий JSON-масив Authenticator в AIC або виділіть увесь масив у
Markdown. Для записів із `service`, `account` і `secret` з’явиться дія
**Convert and save security blocks**. Вона створює секції одного або кількох
блоків `aic` і явно зберігає нотатку. Секції розділяються окремим `---`, а назви
необов’язкові. Переповнення переходить у наступний блок без втрати полів.

`service`, `account` і нотатки стають текстовими частинами; `secret` — TOTP
`#|`, а `password` — прихованою частиною `*|`. Безпечні HTTP(S)-адреси сервісів
отримують окреме поле, яке можна відкрити. Додаткові рядкові поля зберігаються
прихованими. Некоректні записи, дублікати ключів або непідтримувані значення
зупиняють усе перетворення без часткового запису. Межі: 256 записів і 1 МіБ
UTF-8. Початкові секрети не обрізаються і не «виправляються» здогадками.

Перетворюється лише поточний текст або виділення. AIC не сканує обліковий запис,
не читає буфер обміну автоматично й не змінює типи нотаток Standard Notes.
Markdown, JSON, експорт і скопійовані значення лишаються відкритим текстом.

### Копіювання, вставлення і генерація

Натисніть назву поля, щоб скопіювати назву, або значення, щоб скопіювати
значення. Після успіху коротко з’являється **Copied**. Tab переміщує фокус,
Enter/Space активує вибране поле. Для порожнього поля доступні **Paste** і
видалення; для заповненого ці кнопки приховані. Заміни значення окремою дією
немає — використовуйте **Edit** для Markdown-блоку. Заголовок блоку зберігає
дію повного копіювання.

Paste читає останній текст із буфера лише після натискання користувача. AIC не
має історії буфера. Якщо доступ заборонений, недоступний або завершується
тайм-аутом, з’являється масковане поле лише для вставлення. Порожній буфер нічого
не змінює.

Порожнє парольне поле `*|` на екранах ширше 600 px може показувати **Generate
password**. На малих екранах ця дія прихована. Типове значення має 24 символи;
довжина 8–128, набори великих і малих літер, цифр та символів налаштовуються.
Генератор працює локально через Web Crypto, не перезаписує наявний пароль, не
показує і не копіює його автоматично.

### Одноразові значення і назви

Шаблон одноразових кодів додає невикористані значення `1|`. Успішне копіювання
переводить код у `0|`. Натискання використаного коду повертає `1|` без
копіювання; наступне натискання копіює й знову позначає його використаним.

Необов’язковий `# Заголовок групи` називає картку, а `## Назва секції` — окрему
секцію. Без назви використовується нейтральний заголовок Security.

## Компактні групи та Markdown-джерело

Картка AIC має фільтр, помітні розділювачі секцій і компактне меню додавання.
Фільтр шукає лише видимі назви та значення; приховані секрети й одноразові коди
не індексуються. Це локальний стан інтерфейсу, який не змінює нотатку.

Тип кожного значення задає розділювач:

- `|` — текст;
- `*|` — секрет;
- `#|` — TOTP;
- `_|` — картка;
- `1|` — невикористане одноразове значення;
- `0|` — використане одноразове значення.

```aic
# Сервіси
Service | Example
| example@example.invalid
Password *|
---
## Необов’язкова назва
Service | Another example
Password *|
```

Порожній, Card і One-time codes — шаблони тих самих типізованих значень. Порожній
текстовий рядок можна використати для email, імені користувача чи іншого
ідентифікатора. Застарілі YAML Properties, двокрапкові поля й попередні формати
Security лишаються точним вихідним Markdown для ручного редагування.

Одна кнопка **Show Markdown source / Show preview** перемикає всі прев’ю в
поточній нотатці. Вона не відкриває інший редактор, не зберігає текст і не
скидає Undo. Сирий Markdown може показати масковані значення, тому це явний
доступ до джерела.

## Межі й відновлення

Один блок має до 16 секцій, 64 рядків на секцію, 64 типізованих значень на рядок,
65 536 UTF-16 одиниць тексту на блок і 16 384 закодованих одиниць на рядок. Дії,
що перевищують межу, вимикаються; **New block** лишається доступною. Значення не
обрізаються.

Некоректне прев’ю показує рядок і колонку та дає **Edit** у відповідному місці.
Порада не повторює пароль, TOTP seed або сирий текст помилки.

## Mermaid, цитати та код

Mermaid редагується як Markdown-код із живим прев’ю. У прев’ю є Copy, одна
іконка Edit і масштаб. Візуальний конструктор, drag-and-drop та поворот прибрані.
`>` — інформаційна цитата, `!>` — попередження, `!>>` — помилка, а
`>>> … <<<` лишається блоком details. Незавершений потрійний backtick не ховає
джерело; готовий блок переходить у прев’ю після виходу курсора.

## Встановлення

1. Відкрийте **Preferences → Plugins → Install Custom Plugin**.
2. Вставте `https://ldzyha.github.io/standard-notes-aic/ext.json`.
3. Виберіть **AIC** у меню редактора нотатки.

Для поточного випуску й ручних пакетів використовуйте
[`RELEASE_INSTALL.md`](RELEASE_INSTALL.md).

## Розробка і перевірка

Потрібні Node.js 20.19+ або сумісний новіший LTS і npm.

```bash
npm ci
npm run check
npm run build:browser
```

`npm run check` перевіряє формат, lint, TypeScript, тести й production build.
Браузерний пакет експериментальний; перед реальними секретами виконайте умови з
[`browser/VERIFICATION.md`](browser/VERIFICATION.md).

## Дані й розповсюдження

AIC не додає сервер і не змінює модель синхронізації Standard Notes. Джерелом
даних лишається Markdown нотатки. Маскування — лише візуальне: джерело, експорт,
буфер та інші редактори можуть містити відкриті секрети.

Поточні пакети публікуються на GitHub. Подання до VS Code Marketplace, Chrome Web
Store і Microsoft Edge Add-ons описане у двомовному
[`MARKETPLACE_HOWTO.md`](MARKETPLACE_HOWTO.md), але ще не оголошене завершеним.
