# AIC Notes: Markdown-файли на ваших пристроях

[English](README.md)

[Умови й приватність](https://aic.dzyha.com/terms/uk/) ·
[Випуски та встановлення](https://aic.dzyha.com/releases/uk/) ·
[Як писати документи](https://aic.dzyha.com/how-to/uk/)

AIC Notes — це одна нотатка: один Markdown-файл, поділений на сторінки рядками
`---`. Файл вибирається один раз; кожен запуск відкриває той самий файл.
Налаштувань шифрування, пароля, Lock чи зашифрованого експорту немає. Захист і
синхронізація належать пристрою та вашому сховищу.

## Вибір нотатки

Перший запуск показує **Choose your note file** з двома діями:

- **Open note file** — відкриває наявний Markdown-файл.
- **Create new note** — створює новий файл; запропонована назва `aic.md`.

**Note options** (кнопка ⋯) містить **Download note**, **Open note file…**
(або **Replace from file…**, див. нижче) і посилання довідки.

## Редагування й збереження

Там, де браузер може записувати файли (File System Access: Chrome, Edge та інші
браузери Chromium на комп’ютері), зміни зберігаються безпосередньо у файл
нотатки. Заголовок показує **Saved to aic.md**, **Saving…**, **Unsaved** або
**Save failed**. Автозбереження, Ctrl/Cmd+S і Save редактора мають одного
власника. Запис відбувається лише тоді, коли файл досі містить текст, який AIC
востаннє прочитав або записав:

- **Файл змінено деінде** — запис зупиняється, чернетка лишається. Збережіть її
  через **Download note**, потім **Reload note file** відкриє текст файла.
- **Потрібно знову надати доступ** — застосунок показує останню копію з
  браузера лише для читання й одну кнопку **Reconnect note file**. Незбережена
  чернетка лишається в редакторі й зберігається після відновлення доступу, якщо
  файл не змінився; якщо змінився, застосунок питає перед заміною чернетки.
- **Файл переміщено чи видалено** — він ніколи не створюється заново.
  Застосунок знову показує екран вибору. Порожній або новий файл починається з
  останнього збереженого тексту. Файл, що вже має текст, відкривається, а не
  перезаписується, і перед заміною тексту, що зберігається лише в цьому браузері,
  застосунок питає й пропонує його завантажити.
- **Інше вікно зберегло нотатку** — запис зупиняється, чернетка лишається;
  скористайтеся **Reload note file**.

Поки ви друкуєте, незбережений текст також зберігається в сховищі браузера й
прибирається після успішного запису. Якщо сторінку закрито чи зупинено раніше,
наступний запуск повертає текст як незбережений, коли нотатка не змінилась. Якщо
змінилась, **Recover unsaved text** питає: **Open as a copy** додає текст новою
сторінкою в кінець нотатки без збереження; **Download unsaved text**; або
**Discard unsaved text**.

Інші браузери (Firefox, Safari та браузери на iOS і Android) зберігають нотатку
у власному сховищі браузера. Заголовок показує **Saved in this browser**.
**Download note** зберігає копію як файл, а **Replace from file…** завантажує в
нотатку текст файла. Сховище браузера може бути очищене; завантажені файли
лишаються під вашим контролем.

Робочі простори попередніх версій не переносяться й більше не показуються. Нічого
не видалено: файли лишаються там, де були, а робочий простір, що жив лише в
браузері (Firefox, Safari), лишається в сховищі браузера, доки не очищено дані
сайту. Експорту для нього немає. Синтаксис секретних полів маскує
значення на екрані; Markdown-файл не шифрується.

## Сторінки

Рядок `---` після порожнього рядка ділить нотатку на картки сторінок;
`--- <шлях-або-URL>` стає заголовком картки з цією ціллю. Для веб-URL дія
**Open target** відкриває його в новій вкладці. Шлях до файла (записаний
повністю, наприклад `--- /home/me/src/app.ts`) показується лише текстом:
браузер не може його відкрити.

## Офлайн і оновлення

Інтерфейс працює офлайн після першого успішного завантаження й встановлення кешу.
**Update app** з’являється для готового оновлення, зберігає чернетку та
перезавантажує застосунок. Помилка запису чи нові правки залишають редактор
відкритим. **Install AIC Notes** — окрема дія браузера. Локальний вбудований AI
необов’язковий; звичайне редагування працює без нього. AIC не надсилає нотатки
на сервер і не синхронізує файли. За потреби використовуйте власну папку Google
Drive або іншого сховища.

`npm run build:pwa` створює `dist-pwa/` для HTTPS на `aic.dzyha.com`.
`sw.js`, `index.html` і маніфест мають перевіряти оновлення; хешовані ресурси
можна кешувати незмінними. Конфігурація — `pwa/_headers` і `firebase.pwa.json`.
Остання спрямована лише на Firebase Hosting сайт `aic-dzyha-com`:

```sh
npm run build:pwa
firebase deploy --only hosting --project dzyha-com --config firebase.pwa.json --non-interactive
```

Локальна збірка не публікує сайт. DNS керується Squarespace Domains і
налаштуванням домену Firebase. Автоматизація оновлень розширень описана у
[EXTENSION_UPDATES.md](EXTENSION_UPDATES.md).
