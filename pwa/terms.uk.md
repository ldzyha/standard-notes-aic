Ця сторінка описує обробку даних в AIC і межі локального зберігання. Використання
програми регулює ліцензія, що постачається з установленим пакетом; ця сторінка
не створює окремої договірної угоди. Ліцензія вихідного коду розширення VS Code
доступна в [AIC Notes](https://github.com/ldzyha/aic-notes/blob/main/LICENSE).

## Ваші файли та пристрої

На початковому екрані **New workspace**, **Open files** та **Open folder** створюють
локальний Markdown-простір без пароля. Усередині відкритого простору **Open files**
та **Open folder** додають файли з його поточним локальним або зашифрованим
режимом зберігання. **Save** або Ctrl/Cmd+S зберігає нотатки, шляхи й назви
локального простору як **незашифровані дані на цьому пристрої**.
Локальні простори доступні після перезапуску й не блокуються автоматично. Браузер
може очистити або видалити локальні дані; зберігайте експортовані копії важливого.

Список файлів показує `.md` незалежно від регістру. Новий імпорт файлів і папок
додає лише такі файли та пропускає папки `.git` і `node_modules`. Відкриття папки
імпортує знімок: редагування й локальне збереження не записують зміни до вихідної
папки. **Save plaintext copy** або **Export folder** явно записують читабельні
файли. Наявні зашифровані набори зберігають інші типи побайтово, навіть коли
список Markdown їх приховує; експорт папки містить і ці збережені файли.

**Encrypt workspace** створює окрему копію, захищену парольною фразою. Початковий
незашифрований простір лишається на пристрої, доки ви не приберете його через
**Remove local workspace**. Ця дія видаляє лише локальну копію застосунку, а не
вихідні чи експортовані файли або зашифровану копію. Створення зашифрованої копії
не шифрує й не стирає попередню відкриту копію.

PWA, файловий редактор Chrome/Edge та редактор зашифрованих файлів VS Code
відкривають однакові `.aicnotes`. Кожна зашифрована сутність має власну парольну
фразу й може містити нотатки, окремі файли або папки проєктів. Необов'язкові назви
не визначають ключів: назви локального простору незашифровані, а назви
зашифрованої сутності містяться в захищених даних. Бібліотека нотаток сторінок
Chrome/Edge та файловий хост VS Code і далі потребують пароля шифрування.

Захищені файли використовують на пристрої наявний формат AIC:
PBKDF2-HMAC-SHA256 із 600 000 ітерацій і випадковою сіллю, потім автентифіковане
AES-256-GCM. Парольні фрази не зберігаються. Розблоковані дані й ключі існують
у пам'яті; блокування або перезапуск завершує розблокований стан зашифрованої
сутності. Збережені зашифровані сутності блокуються після п'яти хвилин без
взаємодії; незбережені зашифровані чернетки лишаються відкритими до збереження чи
закриття. Шифрування не захищає скомпрометований пристрій або вже розблокований
редактор. AIC не є незалежно аудитованим менеджером паролів.

Для зашифрованої сутності обраний `.aicnotes` є постійною копією, а кеш браузера
містить шифротекст. Перед записом підключеного файла AIC перевіряє помічені
зовнішні зміни. Він не об'єднує одночасні зміни й не гарантує, що стороння
програма не змінить файл під час запису. Після оновлення сервісом синхронізації
відкрийте файл знову. Невдалі чи конфліктні зміни лишаються в пам'яті для повтору
або експорту; це не резервна копія, стійка до аварії. Закриття може втратити
незбережені зміни.

AIC не надає серверного сховища, відновлення облікового запису чи синхронізації.
Експортовані Markdown-файли або `.aicnotes` можна синхронізувати через Google
Drive чи інший керований вами сервіс. Збережений локально простір браузера не є
синхронізованою папкою. Сервіс має власну політику приватності й обробку
конфліктів; AIC не надає й не контролює його доступ. Зберігайте зашифровані
резервні копії та їхні паролі: розробник не може відновити забутий пароль.

**Save plaintext copy**, **Export folder**, **Restore folder**, експорт Markdown
і копіювання навмисно створюють відкриті дані, включно із секретами. Програми
призначення, історія чи синхронізація буфера та сервіси, яким ви передаєте файли,
можуть отримати ці дані. Експорт або відновлення папки відмовляється
перезаписувати помічені наявні файли, але перервана дія може залишити нові файли.

## Робота офлайн і з'єднання

Після першого успішного завантаження онлайн і встановлення кешу програми
інтерфейс PWA та локальні файли працюють офлайн. Перший візит і оновлення
програми потребують з'єднання із цим сайтом. Сервіси браузера або операційної
системи можуть окремо виконувати оновлення розширень, синхронізацію буфера чи
обраних файлів. Локальне сховище AIC не керує цими сервісами.

Хост сайту отримує звичайні запити до файлів програми й документації, включно
з IP-адресою з'єднання. Програма AIC не передає хосту ваші нотатки, парольні
фрази чи ключі шифрування.

## Вбудований AI

Дії **Grammar** та **Improve** використовують локальний `LanguageModel` Prompt
API браузера Chrome, як у Core playground. Вибраний текст нотатки обробляється
на пристрої; AIC не має резервного хмарного AI, токена провайдера чи підключення
AI-облікового запису. AI запускається лише після вибору вами відповідної дії.
Перегляньте запропонований текст перед **Apply**; застосовану зміну можна
скасувати в редакторі.

Після вашої явної дії AI Chrome може завантажити свою модель. Це завантаження,
яким керує браузер, потребує з'єднання. Коли модель доступна, підтримувані
пристрої можуть виконувати AI офлайн. Доступність залежить від API браузера,
пристрою, вільного місця та підтримуваної мови. Браузери без цього API все одно
редагують нотатки офлайн. Поради AI можуть змінити зміст або бути помилковими;
перевіряйте їх перед збереженням чи передаванням.
[Prompt API Chrome та його вимоги](https://developer.chrome.com/docs/ai/prompt-api).

## Політика нотаток сторінок для Chrome та Edge

Наведена нижче політика стосується наявного браузерного редактора нотаток
сторінок, його дозволів, зашифрованої бібліотеки й заяви Limited Use для Chrome
Web Store. Його мережеві обмеження поширюються саме на цей редактор. Відкриття
публічної документації чи посилання на джерело є звичайною навігацією браузера.
