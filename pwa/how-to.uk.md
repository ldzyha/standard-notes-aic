# Як написати корисний документ

> **Публічний посібник з написання:** <https://aic.dzyha.com/how-to/uk/>

[English](/how-to) · [Відкрити AIC Notes](/) · [Умови та приватність](/terms/uk/) · [Випуски та встановлення](/releases/uk/)

Скористайтеся [письмовим промптом Document Design Kit](https://ddk.dzyha.com/prompt.html),
щоб перед написанням визначити ініціатора, мету, читача й наступну дію. Це
публічний посібник автора; відкриття сторінки або копіювання промпту не надсилає
вашу нотатку нікуди.

## Напишіть перший достатній документ

Дайте читачеві лише розуміння, потрібне для наступної дії. Назвіть результат,
визначте найменший корисний набір питань і дайте на кожне пряму відповідь. Для
одного пояснення використовуйте короткий текст, для незалежних пунктів — список,
для послідовної роботи — нумеровані кроки, для порівнянь чи визначень — таблиці,
а для зв'язків, потоків чи розгалужень — Mermaid у fenced-блоці. Відокремлюйте
факти від пропозицій, припущень і невідомого. Не створюйте інший документ лише
через наявний шаблон: доповніть поточний, якщо бракує одного факту.

Markdown є звичайним форматом Notes. Зберігайте заголовки, посилання, fenced-код
і Mermaid, таблиці, details, raw HTML, старі властивості та типізовані поля AIC.
На роздільнику поля в рядку `|`, `*|`, `#|`, `_|`, `1|` і `0|` позначають типи
значень; маскування змінює лише вигляд і не дозволяє розкривати чи експортувати
секрет.

DDK JSON — окремий, явно запитуваний формат обміну для структурованого редактора
DDK. Це не формат імпорту Notes; Notes не перетворює Markdown-нотатки на DDK JSON. Якщо документ DDK потребує багатших
блоків, властивостей або вкладених регіонів, зберігайте його рідний JSON.

Поточний редактор Notes застосовує **Fix grammar** або **Improve** лише до
виділеного тексту чи поточної нотатки. Він не містить шаблонів DDK, структурованих
регіонів або автоматичного заповнення полів. Перед **Apply** перевіряйте кожну
пропозицію: автор відповідає за факти й рішення.

## Передайте агенту наявний контекст

Агент бере контекст проєкту з його єдиної нотатки в корені,
`<назва папки проєкту>.note.md`. Рядки, що містять лише `---`, ділять її на
сторінки; `--- <шлях відносно проєкту>` прив’язує наступну сторінку до цього
файла, а текст перед першим роздільником — загальні нотатки проєкту. Агент читає
початковий текст і сторінку, прив’язану до файла, над яким працює, як ваш
контекст. Нотатка для нього лише для читання, доки ви не попросите її змінити;
сам він нотатку не створює й сторінок не додає.

З командою `aic` результат `aic context resolve --path <file>` — саме цей
контекст. Інші агенти читають нотатку проєкту безпосередньо. Файли `*.note.md`
для окремих файлів і папок зі старіших версій читаються так само, якщо вони є;
нових агенти не створюють. AIC не встановлює пошукового індексу й не надсилає
вміст нотаток агенту автоматично.

Передайте агенту **Instructions for coding agents** із локальної довідки AIC.
У VS Code **Copy Agent Instructions** копіює той самий текст; у довіреному
просторі можна вибрати **Enable AIC Agent Workflow → Copy handoff**. Після
оновлення розширення **Sync Agent Instructions** готує нову копію з хешем вмісту,
не перезаписуючи авторські нотатки чи попередні інструкції. Агент має явно
отримати цей текст або шлях; налаштування не забезпечує автоматичного виявлення
всіма агентами. Доступ до файлів пояснено в [посібнику випуску](/releases/uk/).

## Скопіюйте доповнення AIC до промпту DDK

Це доповнення для AIC, а не копія канонічного промпту DDK. Почніть із поточного
[промпту DDK](https://ddk.dzyha.com/prompt.html), а потім додайте цей текст, коли
результатом має бути нотатка AIC:

```text
Use the DDK method to create the first document sufficient for the reader's next action. Output Markdown unless the user explicitly requests DDK JSON. Preserve AIC headings, links, fenced code and Mermaid, tables, details, raw HTML, legacy properties and typed separators inside fenced aic blocks (|, *|, #|, _|, 1| and 0|). Do not convert an AIC note to DDK JSON or lose its syntax. Do not put secret values in examples, prompts, previews or instructions.
```

## Використовуйте поточного помічника Notes локально

1. Під час першого запуску виберіть **Open note file** для наявного
   Markdown-файла або **Create new note** для нового. Кожен наступний запуск
   відкриває ту саму нотатку.
2. Виділіть текст для перевірки або залиште виділення порожнім, щоб перевірити
   поточну нотатку. Виберіть **Fix grammar** для виправлення орфографії, граматики
   й пунктуації або **Improve** для зрозуміліших формулювань. Локальний AI приймає
   до 14 000 символів; у довшій нотатці виділіть коротший уривок.
3. Перевірте запропонований текст і факти. Виберіть **Apply**, щоб застосувати
   зміни, або **Cancel**, щоб залишити оригінал. Undo у редакторі відновлює текст
   після застосованої пропозиції.
4. У браузерах із підтримкою запису зміни автозберігаються у файл нотатки.
   **Save** або Ctrl/Cmd+S повторює незавершене чи невдале збереження. Інші
   браузери зберігають нотатку в сховищі браузера; стан показує **Saved in this
   browser**. **Download note** зберігає копію як файл. Синхронізацію виконує
   ваша служба зберігання.

AI починає обробку лише після вашої дії. Код, посилання, HTML, старі властивості й секретні AIC-блоки
залишаються захищеними; їхній вміст приховано від локальної моделі. Виділяйте
звичайний текст поза цими частинами. Закриття або перемикання нотатки
очищає попередній перегляд помічника; змінена нотатка чи виділення не отримають
застарілу пропозицію.

Помічник використовує модель Chrome на пристрої, без віддаленої AI-підміни та
ключа провайдера. Перше завантаження моделі, яким керує браузер, потребує
підключення. Коли модель доступна, підтримувані пристрої можуть запускати AI
офлайн; встановленій PWA також потрібне початкове онлайн-завантаження для роботи
її інтерфейсу офлайн. Поточні API базових моделей Chrome не підтримують Android
чи iOS. Мобільне редагування Notes працює офлайн; для AI потрібні також
підтримуване настільне обладнання, API браузера, місце на диску й мова.
[Вимоги Chrome Prompt API](https://developer.chrome.com/docs/ai/prompt-api).

Копіювання промпту в іншу AI-службу підпорядковується її правилам обробки даних.
Вбудований помічник AIC не передає їй нотатки. Не додавайте секретні дані до
промптів, які надсилаєте вручну, і перевіряйте створений вміст перед збереженням
або поширенням.
