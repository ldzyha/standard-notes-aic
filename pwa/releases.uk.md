# Випуски та встановлення

> **Публічні випуски та встановлення:** <https://aic.dzyha.com/releases/uk/>

[English](/releases) · [Відкрити AIC Notes](/) · [Умови та приватність](/terms/uk/)

PWA, браузерне розширення й VS Code працюють зі звичайними Markdown-файлами.
Виберіть файли, редагуйте їх безпосередньо та передавайте між пристроями власною
синхронізацією. Немає пароля застосунку чи зашифрованого формату просторів.
Standard Notes використовує той самий синтаксис із власним сховищем і синхронізацією.

## Почніть тут — підготовлене оновлення зі звичайними файлами

Інструкція описує нову робочу версію. Розгортання, підписані пакети й доступність
у магазинах ще потребують перевірки. Старі записи нижче зберігають контекст своїх
випусків і можуть описувати функції, яких у цій версії вже немає.

| Де працювати           | Що відкрити                                | Куди записуються зміни                                        |
| ---------------------- | ------------------------------------------ | ------------------------------------------------------------- |
| [AIC Notes PWA](/)     | Ваш єдиний файл нотатки, вибраний один раз | У файл нотатки або, без доступу до файлів, у сховище браузера |
| Панель Chrome чи Edge  | Ваш єдиний файл нотатки                    | У файл нотатки                                                |
| VS Code desktop чи Web | Markdown через **AIC Markdown**            | У файлового провайдера з рідними Save/Undo                    |
| Standard Notes         | Нотатку з редактором **AIC**               | У Standard Notes за його налаштуваннями                       |

Три файлові редактори працюють з одним синтаксисом. Standard Notes не відкриває
і не синхронізує цей файл автоматично; переносьте вміст туди явно. Старі
`.aicnotes` не відкриваються й не конвертуються. Наявні файли лишаються без змін.

### Відкриття, створення й збереження

1. Під час першого запуску виберіть **Open note file** або **Create new note**
   (запропонована назва `aic.md`) у PWA чи **Open note file** або **Create note
   file** у браузерній панелі. Наступні запуски відкривають той самий файл.
2. Пишіть у Preview чи джерелі Markdown. **Save** або Ctrl/Cmd+S завершує
   відкладений запис. Дочекайтеся **Saved to aic.md** у PWA або **On disk** у
   браузері; **Unsaved**, **Saving…** чи **Reconnect** не підтверджують запис.
3. Для поновлення дозволу виберіть **Reconnect note file** у PWA або **More
   options → Reconnect access** у браузері. До того PWA показує останню
   збережену копію лише для читання. Браузер не відкриває абсолютного шляху ОС.
4. Якщо інша програма змінила файл, збережіть чернетку окремою копією:
   **Download note** у PWA, де **Reload note file** потім завантажує файл;
   **Export unsaved draft** у браузері, де **Discard my changes and reload**
   завантажує файл. Видалений файл не створюється заново автоматично.
5. Видалення застосунку не видаляє файл нотатки. Деінсталяція й очищення
   браузера можуть прибрати локальні копії; вони не замінюють збережені файли
   та резервні копії.

Прямий запис потребує File System Access (браузери Chromium на комп’ютері).
Інші браузери, зокрема Firefox, Safari й мобільні браузери, зберігають нотатку
PWA у сховищі браузера: стан показує **Saved in this browser**; **Download
note** зберігає файл, а **Replace from file…** завантажує його. Робочі простори
попередніх версій не переносяться й не показуються; нічого не видалено. Їхні
файли лишаються там, де були, а робочий простір, що жив лише в браузері, лишається
в його сховищі, доки не очищено дані сайту.

### Одна нотатка у фокусі

VS Code і редактор коду aic ведуть одну нотатку на проєкт у корені проєкту,
`<папка проєкту>/<назва папки проєкту>.note.md`; сторінки прив’язуються за
шляхом усередині проєкту (`--- src/index.js`). PWA і браузерне розширення
використовують один файл нотатки, який ви там вибираєте; сторінки прив’язуються
за URL. `<project>.note.md` зі старіших версій використовується як є;
`<папка>/aic.md`, який використовував VS Code 61.6.5, більше не відстежується,
тож скопіюйте його сторінки в нотатку проєкту. Нічого не переноситься й не
видаляється. PWA показує всю нотатку, браузерна
панель — сторінку активної вкладки, VS Code — відкритий документ.

У нотатці рядок `---` після порожнього рядка починає нову сторінку, а
`--- <шлях-або-url>` прив’язує наступну сторінку до цього шляху файла
чи вебадреси. Кожна сторінка показується карткою; **Open target** на
прив’язаній картці відкриває вебадресу в новій вкладці. PWA показує шлях файла
лише текстом.

Браузерна панель показує лише сторінку, прив’язану до точної адреси активної
вкладки. Для адреси без сторінки показується порожня картка; сторінка додається
в кінець нотатки, щойно ви почнете писати, а саме відвідування нічого не
записує. Зміна вкладки змінює показану сторінку й очищує Undo попередньої.
Вкладка без адреси `http` чи `https` показує всю нотатку. У VS Code Linked Note
показує сторінку нотатки проєкту, прив’язану до шляху активного файла
усередині проєкту.

Для запам’ятованого розташування браузера **Continue** поновлює доступ до
файла нотатки. Папка, запам’ятована попередньою версією, не відкривається:
відкрийте її `aic.md`. Інші розташування доступні в **More options**. Якщо
запит дозволу не з’являється в бічній панелі, виберіть **More options → Open AIC
in tab** і продовжте там. Початкова панель перевірить доступ після повернення.

### Використовуйте контекст проєкту з агентом

Готові відповіді, рішення й прев’ю містяться в допоміжних `.note.md`.
Для `project/src/parser.ts` перегляньте `project/project.note.md`,
`project/src.note.md` і `project/src/parser.note.md` у визначеному проєктом порядку.
Включайте нотатки в доступний семантичний чи текстовий пошук агента; перевіряйте
поточне джерело, перш ніж вважати стару нотатку чи прев’ю реалізованим рішенням.
Авторські нотатки лишаються для читання без явного запиту змінити саме їх.

Ці правила є в **Instructions for coding agents** локальної довідки AIC. У VS Code
доступні **Copy Agent Instructions** і **Enable AIC Agent Workflow → Copy handoff**
для довіреного простору; **Sync Agent Instructions** оновлює передачу після
оновлення. Явно передайте текст або шлях агенту. Це не додає пошукової служби,
не надсилає нотаток автоматично й не перевизначає інструкцій проєкту.
Дивіться [приклади контексту й шляхів](/how-to/uk/).

### Написання, копіювання й повторне використання блоків

Наберіть `/`, щоб вибрати шаблон документа чи блока. Залиште лише потрібне
читачеві: абзаци, заголовки, списки, таблиці, код, Mermaid, details і типізовані
поля AIC. [Інструкція How to](/how-to/uk/) посилається на актуальний
[метод DDK](https://ddk.dzyha.com/prompt.html) і готовий додаток до промпту для AIC.
Структурований JSON DDK — окремий формат, не імпорт Markdown.

Порожнє секретне поле AIC у джерелі Markdown:

````markdown
```aic
## Account
Login | name@example.invalid
Password *|
```
````

У Preview секрети маскуються. Кнопка копіювання працює без відкриття значення;
джерело й скопійований текст містять саме значення. Маскування змінює показ,
а не шифрує файл. Копіювання невикористаного одноразового значення змінює `1|`
на `0|` і зберігає правку. Генератор паролів заповнює лише порожні редаговані поля.

У PWA **Fix grammar** та **Improve** пропонують необов’язковий ШІ на пристрої.
Виділіть текст, перегляньте пропозицію та виберіть **Apply** чи **Cancel**.
Undo скасовує застосовану правку. Код і секретні блоки не передаються моделі.
Браузеру може знадобитися початкове завантаження моделі; редагування не залежить від ШІ.

### Синхронізація й робота офлайн

Розмістіть файл нотатки в Google Drive, OneDrive, Dropbox, Git чи іншому
обраному місці та відкрийте цей локальний файл у кожній програмі. AIC записує файли, ваш засіб
передає їх. Перед зміною пристрою дочекайтеся запису й завершення синхронізації.
Паралельні зміни потрібно переглядати, а не мовчки перезаписувати.

Відкрийте PWA онлайн один раз для кешування інтерфейсу. Встановіть його з меню
браузера або через **Share → Add to Home Screen**, де це доступно. Кешований
інтерфейс працює офлайн з доступними файлами; зовнішня синхронізація потребує
мережі. Оновлення очікує безпечного збереження чернеток. Якщо запис не вдається,
залиште застосунок відкритим і спершу збережіть копію.

### Встановлення й оновлення розширень

- **VS Code:** використовуйте [Marketplace](https://marketplace.visualstudio.com/items?itemName=ldzyha.aic-notes)
  або перевірений VSIX із [GitHub releases](https://github.com/ldzyha/aic-notes/releases).
  Для завантаженого файла запустіть **Extensions: Install from VSIX…**.
  У code-server: `code-server --install-extension ./aic-notes-VERSION.vsix --force`.
- **Chrome/Edge:** встановіть доступну версію магазину або розпакуйте перевірений
  Chromium ZIP із [GitHub releases](https://github.com/ldzyha/standard-notes-aic/releases).
  У `chrome://extensions` чи `edge://extensions` увімкніть Developer mode та
  **Load unpacked** з папки, що містить `manifest.json`. Для оновлення замініть
  файли в цій самій папці й натисніть Reload після збереження нотаток.
- **Standard Notes:** у **Preferences → Plugins → Install Custom Plugin**
  вставте `https://ldzyha.github.io/standard-notes-aic/ext.json`, потім виберіть
  редактор **AIC**. Оновлення використовують цей самий маніфест.

Версії магазинів можуть відставати від вихідного коду. Для ZIP чи VSIX перевірте
сусідній `.sha256`: `sha256sum -c FILE.sha256` у Linux, `shasum -a 256 FILE` у macOS
або `(Get-FileHash .\FILE -Algorithm SHA256).Hash` у PowerShell. Збірка,
публікація та робота встановленого пакета перевіряються окремо.

Метод написання звірено 14 жовтня з локальною ревізією Core
`c152359c05f572b701651baebca09a49594114bf`, її document guide, правилами форматів
і шаблонами, а також із локальною навичкою письма DDK; публічний DDK guide для
цієї перевірки онлайн не порівнювався.
[Запис перевірки](https://github.com/ldzyha/standard-notes-aic/blob/main/browser/VERIFICATION.uk.md)
фіксує джерела й відмінності. AIC застосовує метод у Markdown; це не злиття
runtime редактора DDK чи його JSON-формату.

Спільне ядро 8.0.0 змінює модель нотатки. Рядок `---` після порожнього рядка

до шляху файла чи вебадреси; сторінки показуються картками з **Open target**.

## Оновлення вебзастосунку — 1 жовтня 2026

Відкриття великого проєкту більше не завершується помилкою після 10 000
переглянутих записів: AIC обходить папку порціями, записує знайдені нотатки,
звільняє тимчасові буфери й продовжує з поточної позиції. Скасування чи пізня
помилка залишає вже записані нотатки доступними. Інтерфейс має компактні панелі
редактора, файлову навігацію, нейтральну світлу й темну тему та зручні для
дотику елементи на телефоні.

Кнопка **Update app** тепер відстежує активацію до завершення, зокрема коли
оновлення вже чекало під час відкриття програми. Вона показує перебіг, дає
повторити завислу активацію та зберігає незбережені чернетки перед
перезавантаженням. Окрема **Install AIC Notes** більше не пропонує вже
використане браузерне запрошення.

Імпорт папки пропускає вкладені `node_modules` і `.git`, а також враховує
`.gitignore` та `.ignore` у вибраній папці й підпапках. Виключені шляхи не
читаються як нотатки. Резервний файловий
діалог браузера може перелічити всю папку ще до передачі вибору AIC.

Натисніть **Open folder** на початковому екрані для імпорту Markdown-нотаток.
Якщо цієї кнопки або нового відсівання немає, спочатку встановіть доступне
оновлення застосунку.

## PWA та переносні файли — 48.4.5 / браузер 0.11.0

Цей випуск поєднує встановлювану PWA на [aic.dzyha.com](https://aic.dzyha.com/)
з [AIC для Standard Notes 48.4.5](https://github.com/ldzyha/standard-notes-aic/releases/tag/v48.4.5),
[AIC Notes 56.4.5](https://github.com/ldzyha/aic-notes/releases/tag/v56.4.5),
експериментальним браузером 0.11.0 та ядром 7.5.0.

- На початковому екрані виберіть **New workspace**, потім **New note**, або
  **Open notes** для файлів, папки чи зашифрованого файла. Зміни автозберігаються
  локально; **Save** або Ctrl/Cmd+S повторює незавершене чи невдале збереження.
  Це не оновлює початкову папку чи Drive.
- Відкриття папки імпортує знімок. **Export Markdown** у меню нотатки й
  **Export all notes** у параметрах простору явно записують читабельні файли;
  **Save encrypted copy** створює окремий захищений `.aicnotes`.
- **Current**, **Shared** і **Global** означають активний файл, найближчу
  батьківську нотатку й нотатку простору/проєкту, зберігаючи початковий поточний
  файл як точку повернення.
- Підтверджене видалення наявного файла відхиляє пізніше збереження замість
  відтворення файла; навмисний новий placeholder і далі може створити файл.
- Файли переносного runtime зберігають перевірені побайтові хеші у Windows
  checkout: перетворення завершень рядків Git не змінює байти пакета.
- Захищені `.aicnotes` відкриваються в PWA, файловому поданні Chrome/Edge та
  VS Code. Їхній кеш містить шифротекст, а необов'язкові назви не визначають
  ключів. Наявні немаркдаунові файли з наборів зберігаються й входять до експорту
  папки. Помічені зовнішні зміни блокують перезапис підключеного файла.
- PWA кешує інтерфейс для роботи офлайн. Перед поданням розширення публікаційні
  процеси перевіряють точний пакет і контрольну суму; схвалення магазином і
  налаштування облікового запису є окремими кроками.
- **Grammar** та **Improve** використовують локальний AI Chrome, як у Core
  playground. Пропозиції переглядаються перед **Apply**, а застосовані зміни
  можна скасувати.

### Встановлення PWA та робота офлайн

1. Відкрийте [AIC Notes](/) онлайн через HTTPS. Дочекайтеся завантаження
   інтерфейсу, щоб установився його офлайн-кеш.
2. У Chrome або Edge виберіть **Install app** у меню чи адресному рядку. На
   iPhone або iPad у Safari виберіть **Share → Add to Home Screen**. Назви дій
   можуть відрізнятися між браузерами.
3. На початковому екрані виберіть **New workspace**, потім **New note**, або
   **Open notes** для файлів, папки чи зашифрованого файла. Зміни автозберігаються
   локально; **Save** або Ctrl/Cmd+S повторює незавершене чи невдале збереження.
4. Для читабельних файлів використовуйте **Export Markdown** у меню нотатки або
   **Export all notes** у параметрах простору. Для захищеної копії використовуйте
   **Save encrypted copy** і оберіть власну папку синхронізації.
5. Відкрийте встановлений застосунок без з'єднання для редагування локальних
   нотаток. Окремий сервіс синхронізації потребує з'єднання для передавання
   експортованих файлів.

Коли з'являється **Update app**, AIC зберігає поточну чернетку перед
оновленням. **Updating…** зникає після відкриття нової версії. Якщо збереження
не вдалося, залиште програму відкритою та повторіть його.
Майте експортовані резервні копії: дані браузера можна очистити,
або браузер може їх видалити. Запис файлів і папок підтримується відповідними
настільними браузерами; інші використовують вибір файлів та завантаження.
Дивіться [обробку даних і межі](/terms/uk/).

### Використання вбудованого AI офлайн

Відкрийте текстову нотатку й виберіть **Grammar** або **Improve**. Chrome може
спершу завантажити локальну модель; цей крок, яким керує браузер, потребує
з'єднання та сумісного пристрою. Коли модель готова, AI може працювати офлайн.
Перегляньте пропозицію та натисніть **Apply**, щоб змінити нотатку; Undo скасовує
цю зміну. AIC не передає нотатку віддаленому AI-сервісу. Доступність AI залежить
від API браузера, пристрою та підтримуваної мови; звичайне редагування лишається
доступним офлайн в інших браузерах. Дивіться [поточні вимоги Prompt API Chrome](https://developer.chrome.com/docs/ai/prompt-api).

## Узгоджений випуск вихідного коду — 48.4.5 / 56.4.5 — 1 жовтня 2026

Цей випуск поєднує [AIC Notes для VS Code 56.4.5](https://github.com/ldzyha/aic-notes/releases/tag/v56.4.5),
[AIC для Standard Notes 48.4.5](https://github.com/ldzyha/standard-notes-aic/releases/tag/v48.4.5)

- Зосереджені вкладки **Current**, **Shared** і **Global** переходять між
  файлом, батьківською нотаткою та нотаткою простору/проєкту без зміни початкового

### VS Code та code-server

Установіть [AIC Notes із VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=ldzyha.aic-notes)
або виберіть версію, її `.vsix` і сусідній файл `.sha256` в
[офіційних випусках GitHub](https://github.com/ldzyha/aic-notes/releases).
Публікації в Marketplace і GitHub незалежні; перевірте версію в обраному каналі.

Для завантаженого VSIX виконайте **Extensions: Install from VSIX…** у палітрі
команд, виберіть файл і перезавантажте вікно. У code-server використовуйте
`code-server --install-extension ./aic-notes-VERSION.vsix --force` з назвою
завантаженого файла. Публікація в Open VSX для code-server є окремою.

Встановлення з Marketplace оновлюються за налаштуваннями VS Code. Для
встановлення з VSIX можна ввімкнути **Auto Update** для AIC Notes й отримувати
оновлення Marketplace.

### Standard Notes

Відкрийте **Preferences → Plugins → Install Custom Plugin** і вставте:

```text
https://ldzyha.github.io/standard-notes-aic/ext.json
```

Виберіть **AIC** у меню редактора нотатки. Наявні встановлення перевіряють той
самий маніфест для оновлень; перезапустіть Standard Notes, якщо лишилася попередня
версія. Завантажувані ZIP і контрольні суми є в
[офіційному архіві випусків](https://github.com/ldzyha/standard-notes-aic/releases).

### Chrome та Microsoft Edge — експериментально

1. Завантажте `aic-browser-chromium-VERSION.zip` і сусідній файл `.sha256` з
   [офіційного архіву випусків](https://github.com/ldzyha/standard-notes-aic/releases).
   Нумерація браузерного пакета та Standard Notes незалежна.
2. Розпакуйте ZIP у постійну папку з `manifest.json` у корені.
3. Відкрийте `chrome://extensions` або `edge://extensions`, увімкніть
   **Developer mode**, виберіть **Load unpacked** і цю папку. Закріпіть AIC та
   натисніть його значок.

Перед оновленням дочекайтеся **Note saved** та експортуйте зашифровану резервну
копію. Замініть файли в тій самій папці й натисніть **Reload** на наявній картці
розширення. Видалення розширення може видалити його локальні нотатки.
Встановлення з магазинів отримують браузерні оновлення після схвалення; для
unpacked-встановлень потрібний Reload. Підготовлений процес публікації не
підтверджує наявність публічної сторінки магазину. Експериментальний пакет нотаток
сторінок ще потребує
[перевірки в Chrome/Edge](https://github.com/ldzyha/standard-notes-aic/blob/main/browser/VERIFICATION.md).

### Перевірка завантаженого пакета

Поруч із кожним релізним архівом або VSIX є файл `.sha256`. У папці завантажень
виконайте `sha256sum -c FILE.sha256` у Linux; у macOS порівняйте
`shasum -a 256 FILE` із сумою у файлі. У Windows PowerShell використовуйте
`(Get-FileHash .\FILE -Algorithm SHA256).Hash`.
