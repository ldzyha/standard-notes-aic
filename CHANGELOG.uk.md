## 48.4.5 — 2026-10-01

Послідовність випуску 48 · 4 нові можливості · 5 виправлених помилок. Узгоджено
з AIC Notes для VS Code 56.4.5, експериментальним браузером 0.11.0 та спільним
ядром 7.5.0.

### F01 — Локальні простори з необов'язковим шифруванням

PWA відкриває локальні Markdown-простори й сумісні `.aicnotes`. Збереження на
пристрої не оновлює початкову папку чи Drive: для передавання явно використовуйте
**Export Markdown**, **Export all notes** або **Save encrypted copy**. Браузерне
файлове подання та VS Code зберігають таку саму парольну межу і кеш шифротексту.

### F02 — Зосереджена навігація файлами й телефоном

**Current**, **Shared** і **Global** ведуть до поточного файла, найближчої
батьківської нотатки та нотатки простору/проєкту, не втрачаючи початковий файл
і власність нативного редактора. Пошук у списку Notes, навігація папками,
компактний заголовок телефона та явні **New workspace**, **New note** і
**Open notes** належать до цього результату. Посібник посилається на живий метод
DDK; AIC зберігає Markdown і свій розширений синтаксис, а не DDK JSON.

### F03 — Необов'язкові локальні Grammar та Improve

Сумісний Chrome показує локальну пропозицію перед **Apply**. Захищений Markdown,
звичайне редагування й Undo залишаються головними, а модель не потрібна офлайн.

### F04 — Перевірка випуску готова для явного ввімкнення

Процес публікації перевіряє точний пакет і сусідню контрольну суму. Облікові дані,
GitHub-випуск і схвалення магазином є окремими діями; цей запис не підтверджує
оновлення жодного магазину.

### Виправлення

1. Ліміт Markdown-папки рахує вибрані Markdown-файли, а не сторонні папки.
2. Читання папки обмежене й скасовується без втрати активного редактора чи
   незбереженої чернетки та без пізнього/часткового імпорту.
3. Відновлення redirect/cache зберігає двомовні сторінки й офлайн-застосунок без
   очищення сховища нотаток.
4. Підтверджене видалення наявного файла відхиляє пізніше збереження замість
   відтворення файла; навмисний новий placeholder і далі може створити файл.
5. Файли переносного runtime зберігають побайтові хеші в Windows checkout, а Git
   не змінює їх перетворенням завершень рядків.

### Раніше підготовлені деталі

- Додано адаптований насамперед для мобільних пристроїв інтерфейс і локальні
  дії Grammar / Improve з вбудованою моделлю браузера, захистом Markdown,
  переглядом пропозиції та скасуванням через Undo.
- Умови, приватність, історія випусків та встановлення доступні двома мовами
  на `aic.dzyha.com/terms` і `aic.dzyha.com/releases`, також офлайн.
- Виправлено відкриття публічних сторінок і застосунку після перенаправлення HTML
  у Firebase. Попередні кеші виправляються без зміни сховища нотаток і без
  примусового застосування оновлення.

- Виправлено імпорт Markdown-папок, що відхиляв менше ніж 2000 нотаток через
  підрахунок сторонніх папок у їхньому ліміті. Рахуються вибрані `.md`, структура
  зберігається в шляхах нотаток; папки експорту відтворюються з окремою межею,
  а наявні межі вмісту й сканування збережено.

- Метадані й вміст читаються по чотири одночасно, розміри вибраних файлів
  перевіряються до читання байтів, сканування/читання періодично передає керування.
  Скасування не створює часткового імпорту чи пізніх оновлень; читання папки/файла
  має межу 30 секунд, а вікном вибору й далі керує користувач.
- Додано поступ сканування/читання папки й **Cancel opening**. Список показує
  перші 100 відповідних Markdown-файлів із пошуком за назвою та **Show more**,
  зберігаючи поточну нотатку й незбережену чернетку під час фільтрування або
  показу наступних файлів.
- Перевірка канонічних даних повторно використовується для незмінених файлів у
  пам'яті; метадані й дескриптори перевіряються надалі, а формати вмісту та
  шифрування збережено.

### Портативні файлові нотатки з необов'язковим шифруванням

- **New workspace**, **Open files** та **Open folder** відкривають локальні
  Markdown-простори без пароля. **Save** зберігає явно незашифрований знімок
  пристрою; новий імпорт і список використовують лише `.md` та пропускають
  папки `.git` і `node_modules`.
- **Encrypt workspace** створює окрему захищену копію. Початковий відкритий
  простір лишається до підтвердженого видалення з програми. Нотатки сторінок
  браузера й хост зашифрованих файлів VS Code зберігають парольну межу.
- Відкриття папки імпортує знімок; локальне збереження не записує зміни до неї.
  Явно експортуйте читабельні файли або передавайте зашифрований `.aicnotes`
  через керовану вами службу синхронізації. Захищені сутності зберігають
  шифротекст у кеші, файли побайтово та перевіряють помічені зовнішні зміни.
- Наявні немаркдаунові файли лишаються в наборі, навіть якщо їх приховано зі
  списку, і входять до повного експорту папки. Застарілі збереження та видалення
  з іншої вкладки відхиляються; невдалий запис зберігає попередні постійні дані.
- Публікація розширень із перевіркою контрольних сум та PR оновлення спільного
  інтерфейсу доступна для налаштованого процесу випуску. Сторінки магазинів
  лишаються окремими від GitHub-випуску.

## 47.1.0 — 2026-09-29

Послідовність випуску 47 · 1 нова можливість · 0 виправлених помилок.
Узгоджено зі Standard Notes AIC 47.1.0, AIC Notes 55.1.0,
експериментальним браузером 0.10.0 та спільним ядром 7.4.0.

### F01 — Вбудовані інструкції для агентів

Однаковий Markdown-посібник доступний у кожному розширенні без окремого AIC
або його каталогу конфігурації. VS Code копіює інструкції й за явною командою
створює локальну передачу агенту, зберігаючи файли власника. Глобальна
синхронізація більше не запускається. Прості відповіді в документації подаються
прямими твердженнями.

### Браузер 0.10.0

Закріплена нотатка лишається відкритою під час перемикання вкладок. Ввід додає
активну сторінку один раз до Related links разом із тією самою операцією Undo.
Блокування скидає закріплення. Імпорт та експорт мають узгоджені контурні іконки.

## 46.0.2 — 2026-09-24

Послідовність випуску 46 · 0 нових можливостей · 2 виправлені помилки. Випуск
узгоджений із AIC Notes 54.0.2, експериментальним браузером 0.9.2 та ядром 7.3.2.

### Виправлення

1. Коментарі до пов’язаного коду лишаються всередині свого акордеона; заголовки
   компактні, а вкладений вміст читабельний.
2. Незбережені зміни не змінюють фон редактора. Кнопка Save пульсує, доки зміни
   потребують збереження; за налаштування reduced motion індикатор статичний.
   Лише підтвердження хоста позначає чернетку збереженою; помилка не стирає зміни.

## 45.0.1 — 2026-09-24

Послідовність випуску 45 · 0 нових можливостей · 1 виправлена помилка. Випуск
узгоджений із AIC Notes 53.0.1, експериментальним браузером 0.9.1 та ядром 7.3.1.

### Виправлення

- Повернуто **Generate password** для кожної порожньої редагованої частини `*|`
  незалежно від назви й ширини панелі. Параметри переносяться на вузькому екрані;
  генерація локальна, заповнені значення й режим читання не допускають перезапису.
- Після успішного копіювання кнопки-іконки ненадовго показують галочку та
  зберігають доступне повідомлення про стан.
- Більші заголовки секцій, нейтральний фон груп і легке чергування сірих рядків
  роблять ієрархію записів зрозумілішою.

## 44.1.0 — 2026-09-23

Послідовність випуску 44 · 1 нова можливість · 0 виправлених помилок. Випуск
узгоджено з AIC Notes 52.1.0, експериментальним розширенням браузера 0.9.0 та
спільним ядром 7.3.0.

### Можливість

- Перероблено читання та впорядкування AIC-записів: назви й значення займають
  природну ширину, ціле значення переноситься до розриву тексту, пароль має
  кнопку копіювання із замком, а `+` лишається біля останнього значення. Легкі
  розділювачі й сенсорні області 44 px зберігають читабельність вузької панелі.
- Вихід із редагування джерела блоку або всієї нотатки сортує рядки кожної секції
  за назвою у природному порядку. Рядки без назви лишаються стабільними наприкінці;
  секції, порядок типізованих частин і точні значення зберігаються. Відкриття
  прев’ю, копіювання та ручне переставлення не сортують документ.

## 41.1.1 — 2026-09-22

### Можливість

- Mermaid спрощено до Markdown-коду й живого прев’ю. Прев’ю має Copy, одну
  спільну іконку Edit та zoom. Visual builder, drag-and-drop і rotate видалені.
- Standard Notes, AIC Notes і browser використовують однаковий shared core 7.0.0.

### Виправлення

- Flowchart editing більше не залежить від нестабільних внутрішніх SVG IDs.
- Render debounce і last-result-wins не дозволяють повільному старому результату
  замінити нове джерело.

## 40.0.1 — 2026-09-22

- `>` — інформаційна цитата, `!>` — warning, `!>>` — error із різними акцентами
  та легким фоном; `>>> … <<<` лишається details.
- Quote та italic мають менший шрифт і більші відступи між блоками.
- Незавершений три-backtick fence лишається редагованим до завершення/focus out.

## 39.0.1 — 2026-09-22

- Збільшено простір між headings, quotes і lists.
- Thematic break відображається як центрована лінія 50–100 px із вертикальними
  відступами без зміни висоти при source reveal.

## 38.1.1 — 2026-09-22

- Account preset замінено порожнім text row для email/username.
- Password і TOTP є окремими необов’язковими полями.
- На вузьких екранах label та values переносяться разом; fixed min-width і
  values-only scroll видалені.
- Password generation приховано на ширині 600 px або менше.

## 37.2.0 — 2026-09-15

- Copy section копіює одну AIC section як окремий fenced block без зміни source.
